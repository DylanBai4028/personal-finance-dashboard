How categories work

Every account in this ledger — real bank/card accounts and spending categories alike — is a colon-separated path, e.g. Expenses:Food:Groceries or Assets:YourBank:Checking. The first segment is the type (Assets, Liabilities, Income, Expenses, or the internal Transfers pseudo-type used for money moving between your own tracked accounts). Every transaction is categorized by a rules file first (merchant pattern → category), falling back to an LLM for anything unmatched — a repeat merchant only ever needs that fallback once, then it becomes a rule. source: llm rules stay visibly tagged apart from ones written by hand, so an auto-categorization never silently passes as reviewed.
